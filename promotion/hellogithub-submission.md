# HelloGitHub 投稿与 Gitee 项目页素材

这份文案用于第一轮国内推广。重点不是“玄学”或“算命”，而是“零依赖、可试玩、结构化 AI Agent 决策分析”。

## HelloGitHub 投稿

项目地址：

```text
https://github.com/RobbyShao-8ag/yice
```

类别：

```text
Python 项目
```

项目标题：

```text
零依赖的 AI 多 Agent 决策参考系统
```

项目描述：

```text
易策是一个用周易“时、位、变”思想组织多 Agent 流程的 Python 决策参考系统。用户输入现实问题后，系统会从环境、资源、风险、策略、长期和复盘六个角度生成结构化报告。CLI 版本只依赖 Python 标准库，无需 API Key 也能先跑本地演示，适合学习多 Agent pipeline、数据驱动设计和传统文化与 AI 结合的实现方式。
```

亮点：

```text
很多 AI 周易项目只是把卦象当提示词装饰，易策把 64 卦、爻辞、场景映射和六爻角色做成可检查的数据与流程。它可以无 API Key 运行本地演示，也可以配置 OpenAI-compatible API 升级为多模型推演；对初学者来说，能直接从 main.py、agents/ 和 data/ 看懂一个多 Agent 系统如何拆分职责。
```

示例代码：

```bash
git clone https://github.com/RobbyShao-8ag/yice.git
cd yice
python main.py
```

示例输入：

```text
我有一个 AI 工具原型和两个试用客户，但现金流只能支撑4个月，现在是否应该全职投入？
```
